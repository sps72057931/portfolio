# Shivendra Pratap Singh: Portfolio

React + Vite single-page portfolio.

## Run locally
    npm install
    npm run dev

## Customise
All content lives in `src/data.js`. Links to your profiles, projects and certificates are set here too.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. On vercel.com choose **Add New, Project**, then import the repo.
3. Vercel auto-detects Vite (build `npm run build`, output `dist`). Click **Deploy**.

Or with the CLI: `npm i -g vercel && vercel`.
